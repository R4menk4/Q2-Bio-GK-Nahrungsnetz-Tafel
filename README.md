# Nahrungsbeziehungen auf der Wiese

Interaktive Tafelversion für Biologie Q2 im Grundkurs. Nach der Begriffseinführung lassen sich die vier Arten auf die Trophieebenen ziehen und durch Nahrungspfeile verbinden. Alle Programmdateien liegen im Stammordner. Die Tafelversion startet über `index.html`.

Die Bildkarten und ihre Entstehung sind in `Bildnachweise-Tafel.txt` dokumentiert. Der [NABU](https://baden-wuerttemberg.nabu.de/natur-und-artenwissen/voegel/vogelportraets/greifvoegel/der-turmfalke) und die [Stiftung Rheinische Kulturlandschaft](https://www.rheinische-kulturlandschaft.de/arten/gemeiner-grashu%CC%88pfer/) beschreiben die Ernährungsweisen von Turmfalke und Gemeinem Grashüpfer.
